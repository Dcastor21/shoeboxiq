# ShoeboxIQ

A private document-intake assistant for small tax offices. It runs entirely on the office's own
computer: it sorts client tax documents, reads the key numbers with the page they came from, and
lists what's missing. Nothing is sent to the cloud.

> **Status: Skeleton phase.** This is a portfolio project built to production standards.
> It is **not** supported for real client documents. Use only the synthetic test data in this repo.
